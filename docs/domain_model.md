# 도메인 모델
## 회원
**회원가입:**
- **일반 회원/어드민 회원 구분:** 회원가입 시, 기본값은 '일반 회원'으로 설정합니다. 어드민 권한은 관리자 페이지에서 특정 사용자에게 부여하거나, 별도의 어드민용 회원가입 페이지를 통해 가입을 허용합니다.
- **필수 입력 정보:** 아이디(이메일 형식), 비밀번호, 이름, 휴대폰 번호.
- **유효성 검증:** 아이디 중복 확인, 비밀번호 규칙(특수문자, 숫자 포함), 이메일 형식 유효성 검사.

**로그인:**
- **인증 방식:** 아이디(이메일)와 비밀번호를 이용한 **JWT(Json Web Token)** 기반 인증 방식을 사용합니다. 로그인 성공 시 JWT를 발급하고, 이 토큰을 통해 사용자 정보를 확인합니다.
- **보안:** 비밀번호는 **해시(SHA-256 등)** 암호화하여 저장하고, 로그인 시 입력된 비밀번호를 동일한 방식으로 해시화하여 비교합니다.

**내 정보 보기 및 수정:**
- **조회:** 로그인한 사용자의 이름, 이메일, 휴대폰 번호 등 개인 정보 조회.
- **수정:** 이름, 휴대폰 번호 등 개인 정보 수정. 이메일은 변경 불가하도록 설계.

**패스워드 변경:**
- **절차:** 현재 비밀번호를 입력받아 확인 후, 새 비밀번호로 변경합니다. 보안 강화를 위해 새 비밀번호 입력 시 기존 비밀번호와 다른지 확인하는 로직을 추가합니다.

**회원 탈퇴:**
- **절차:** 회원 탈퇴 요청 시 비밀번호를 다시 확인하는 과정을 거칩니다. 탈퇴 시 사용자의 모든 개인 정보를 삭제하거나 비활성화 상태로 변경합니다. (예: `is_active=false`)

### User
_Entity_  
_Aggregate Root_
#### 속성
- `id`: 아이디
- `email`: 이메일, unique
- `password`: 패스워드,
- `nickname`: 이름,
- `phone`: 휴대폰 번호, 
- `status`: `UserStatus` 회원상태
- `role`: `ROLE` 회원 구분
- `UserDetail`: `UserDetail` 1:1

### UserDetail
#### 회원상세
_Entity_
- `gender`: `Gender` 성별
- `birth_date`: 생년월일
- `userTier`: `UserTier` 회원등급

### UserTier
#### 회원등급
_entity_
#### 속성
`basic`: basic (기본값)  
`silver`: silver  
`gold`: gold  
`platinum`: platinum

### Gender
#### 성별
_Enum_
#### 상수 
`MALE`: 남성  
`FEMALE`: 여성  

### UserStatus
#### 회원상태
_Enum_
#### 상수
`ACTIVE`: 가입완료  
`DELETED`: 삭제

### Role
#### 회원구분
_Enum_
#### 상수
`USER`: 일반유저  
`ADMIN`: 어드민
