# 도메인 모델

## 회원

**회원가입:**

- **일반 회원/어드민 회원 구분:** 회원가입 시, 기본값은 '일반 회원'으로 설정합니다. 어드민 권한은 관리자 페이지에서 특정 사용자에게 부여하거나, 별도의 어드민용 회원가입 페이지를 통해 가입을 허용합니다.
- **필수 입력 정보:** 아이디(이메일 형식), 비밀번호, 이름, 휴대폰 번호.
- **유효성 검증:** 아이디 중복 확인, 비밀번호 규칙(특수문자, 숫자 포함), 이메일 형식 유효성 검사.

**로그인:**

- **인증 방식:** 아이디(이메일)와 비밀번호를 이용한 **JWT(Json Web Token)** 기반 인증 방식을 사용합니다. 로그인 성공 시 JWT를 발급하고, 이 토큰을 통해 사용자 정보를 확인합니다.
- **보안:** 비밀번호는 **해시(SHA-256 등)** 암호화하여 저장하고, 로그인 시 입력된 비밀번호를 동일한 방식으로 해시화하여 비교합니다.

**내 정보 보기 및 수정:**

- **조회:** 로그인한 사용자의 이름, 이메일, 휴대폰 번호 등 개인 정보 조회.
- **수정:** 이름, 휴대폰 번호 등 개인 정보 수정. 이메일은 변경 불가하도록 설계.

**패스워드 변경:**

- **절차:** 현재 비밀번호를 입력받아 확인 후, 새 비밀번호로 변경합니다. 보안 강화를 위해 새 비밀번호 입력 시 기존 비밀번호와 다른지 확인하는 로직을 추가합니다.

**회원 탈퇴:**

- **절차:** 회원 탈퇴 요청 시 비밀번호를 다시 확인하는 과정을 거칩니다. 탈퇴 시 사용자의 모든 개인 정보를 삭제하거나 비활성화 상태로 변경합니다. (예: `is_active=false`)

## 규칙

- 회원가입 시, 기본값은 '일반 회원'으로 설정합니다. 별도의 어드민용 회원가입 페이지를 통해 가입을 허용합니다.
- 현재는 유저가 판매자 역할을 하는 걸로 한다.

## 카테고리

_Entity_  
_Aggregate Root_

### 규칙

- 관리자는 카테고리를 추가할 수 있다.
- 카테고리는 서브 카테고리를 가진다.
- 서브 카테고리는 제한이 없으나 비즈니스적으로 제한을 둔다.

### 속성

- `name`: 카테고리 이름
- `parentId`: 부모 카테고리
- `sortOrder`: 정렬 순서
- `depth`: 깊이
- `slug`: 슬러그
- `isActive`: 활성화 여부. true: 활성화. false: 비활성화 (삭제와 같음)

### 규칙

- 카테고리는 최대 3 depth를 가진다.
- 부모 이동시 자손의 깊이를 재검증해야한다.
- 같은 부모 아래(형제간)에는 동일한 이름이 있으면 안된다.
- 같은 부모 아래(형제간)에는 동일한 slug가 있으면 안된다.
- 부모가 비활성화되면 자식들도 비활성화된다.
- 하위 카테고리가 있으면 삭제할 수 없다.

## 상품

**상품 등록 (어드민):**

- **필수 입력 정보:** 상품명, 가격, 재고 수량, 카테고리, 상품 설명, 상품 이미지.
- **옵션 구현 (무한 뎁스):** 상품 등록 시, **JSON 형식**으로 옵션을 관리합니다. 예)
  `{"색상": {"네이비": {"사이즈": {"M": 10개, "L": 5개}}, "블랙": {"사이즈": {"M": 20개}}}}`
- **관리자 페이지:** 상품 등록 및 수정은 관리자 페이지(Admin Dashboard)에서만 가능하도록 접근 권한을 제한합니다.

**상품 조회:**

- **목록 조회:** 전체 상품 목록, 카테고리별 상품 목록 조회.
- **상세 조회:** 특정 상품의 상세 정보 (상품명, 가격, 설명, 옵션, 재고 등)를 보여줍니다.
- **정렬:** 가격(낮은 순/높은 순), 최신순, 판매량순 등으로 정렬 기능을 제공합니다.

**장바구니:**

- **기능:** 상품 담기, 수량 변경, 상품 삭제.
- **사용자 정보:** 로그인한 사용자의 장바구니 정보는 DB에 저장하여 로그아웃 후에도 유지되도록 합니다. 비회원의 경우 **세션 또는 쿠키**를 이용해 장바구니 정보를 임시 저장합니다.

### Product

_Entity_ , _Aggregate root_

#### 속성

- `name`: 상품명
- `salePrice`: 판매 가격
- `retailPrice`: 원가
- `discountRate`: 할인율
- `description`: 설명
- `modelNumber`: 모델넘버
- `sellerId`: 판매자 아이디
- `minOrderQty`: 최소 주문 수량
- `maxOrderQty`: 최대 주문 수량
- `status`: `ProductStatus` 상품 상태
- `optionGroups`: `OptionGroup`
- `ProductSku`: `ProductSku`

#### ProductSku

_Entity_

#### 속성

- `skuCode`: sku 코드
- `price`: 가격
- `stock`: 재고
- `OptionValue`: `OptionValue` 옵션 값 ( 재고관리 단위 )

#### OptionGroups

_Entity_

#### 속성

- `name`: 이름
- `sortOrder`: 정렬 순서
- `optionValue`: `OptionValue` 옵션 값

#### OptionValue

_Entity_

- `value`: 값
- `sortOrder`: 정렬 순서

#### ProductStatus

_Enum_

#### 상수

- `DRAFT`: 판매시작 전 상태
- `ON_SALE`: 판매중
- `SUSPENDED`: 판매중지
- `RESERVED`: 예약 판매
- `DISCONTINUED`: 단종
